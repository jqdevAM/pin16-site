U0321

Software Incompatibility with Ride Level Control Module

Severity
Medium
Driving
Drivable — book it in
System
Network and communication
Group
Network software

The software in the ride level control module is not compatible with the rest of the vehicle. Air suspension or adaptive damping will fall back to whatever its failure position is. On an air-sprung vehicle that can mean the car settling overnight until it sits on its bump stops, which is uncomfortable, damaging and unpleasant on a rough road.

Possible causes

  • CommonThe ride level control module replaced but never coded to this vehicle
  • CommonUsed module fitted from a different vehicle or suspension specification
  • CommonRide height calibration not performed after fitting
  • CommonSoftware update interrupted during programming
  • CommonWrong part number for the suspension variant

What you might notice

  • Vehicle sitting low, or at an uneven height
  • Suspension warning message
  • Ride height not adjusting
  • Harsh ride
  • Fault present since suspension work

What to check, in order

  1. Check the ride height at all four corners. A car sitting on its bump stops should be driven gently and slowly, not normally.
  2. Ask what was done. Suspension or module work immediately before this appeared is the explanation.
  3. Check whether the ride height calibration was performed after fitting - it is a required step and skipping it produces exactly this.
  4. Check the part number against the vehicle's suspension variant.
  5. Note that headlamp aim follows ride height on many vehicles, so a car sitting wrong may also be dazzling oncoming drivers.
