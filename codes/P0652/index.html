P0652

Sensor Reference Voltage "B" Circuit Low

Severity
High
Driving
Drive only to a garage
System
Powertrain
Group
Computer output circuits and control module

Sensor reference voltage "B" is reading low - the regulated supply the module provides to a group of sensors has been dragged down, usually by a short to earth or by one failed sensor loading the circuit. Every sensor sharing that reference will now be reporting nonsense.

Possible causes

  • CommonOne sensor on the shared circuit failed internally and is loading the reference
  • CommonReference circuit shorted to earth
  • CommonWater in a connector bridging the reference to earth
  • PossibleChafed harness touching the engine or body
  • PossibleFailed control module reference supply

What you might notice

  • Many sensor codes at once
  • Limp mode or reduced power
  • Engine running badly or not starting
  • Check engine light on

What to check, in order

  1. Do not diagnose the individual sensor codes. Fix the reference first and then see which codes actually come back.
  2. Unplug sensors on reference "B" one at a time while watching the reference voltage. Recovery when one is unplugged identifies it immediately.
  3. Look for water in connectors. A wet connector bridging the reference to earth is the classic cause and it is often intermittent with the weather.
  4. Check the harness for chafe points against the engine or body.
  5. Suspect the module only when every sensor on the circuit has been disconnected and the reference is still low.
