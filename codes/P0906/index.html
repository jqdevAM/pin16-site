P0906

Gate Select Position Circuit Low

Severity
High
Driving
Drive only to a garage
System
Powertrain
Group
Transmission and control modules

The gate select position signal is stuck low - typically shorted to earth or open circuit. The module has no usable indication of which gear pair the selector shaft has moved to, so it will refuse to complete a gear change.

Possible causes

  • CommonWiring shorted to earth or open circuit between the sensor and the module
  • CommonCorroded or water-ingressed connector at the gearbox
  • CommonFailed sensor
  • PossibleLoss of the reference voltage or the sensor earth
  • PossibleChafed harness at the gearbox

What you might notice

  • Car stuck in neutral or will not move
  • Gear changes refused
  • Gear display blank
  • Transmission warning message
  • Check engine light on

What to check, in order

  1. Unplug the sensor and check whether the low reading persists at the harness. If it does, the wiring is at fault rather than the sensor.
  2. Check the reference voltage and earth - a lost earth commonly drives a signal high, so a high reading is not always a shorted wire.
  3. Inspect the connector for corrosion and water.
  4. Look for other codes sharing the same reference circuit before condemning this sensor.
  5. Run the position calibration after any repair.
