P2195

O2 Sensor Signal Stuck Lean (Bank 1 Sensor 1)

Severity
Medium
Driving
Drivable — book it in
System
Powertrain
Group
Fuel and air metering

The upstream oxygen sensor on bank 1 is stuck reporting lean - too much air for the fuel - and not moving from it. This sensor controls fuelling, and a healthy one switches constantly as the module hunts either side of the ideal mixture. One that sits still has usually stopped responding, though it can also be reporting a real problem it cannot see past.

Possible causes

  • CommonAged or contaminated oxygen sensor
  • CommonExhaust leak upstream of the sensor
  • CommonSensor poisoned by oil, coolant or silicone sealant
  • CommonWiring or connector fault
  • PossibleGenuine mixture problem - a vacuum leak, a fuel delivery fault, a leaking injector
  • PossibleHeater circuit fault, so the sensor never reaches working temperature

What you might notice

  • Check engine light on
  • Worse fuel economy
  • Failed emissions test
  • Rough running or hesitation
  • Black smoke in the rich case

What to check, in order

  1. Watch the sensor on the live data screen with the engine warm. An upstream sensor should switch several times a second at idle - one that sits at a fixed value has stopped working.
  2. Check for exhaust leaks upstream of the sensor. Air drawn in through a leak makes a working sensor report lean.
  3. Read all codes. Fuel trim codes alongside this one suggest the mixture really is wrong.
  4. Check the sensor's heater circuit - a sensor that never gets hot never starts switching.
  5. Ask whether silicone sealant was used recently. It poisons oxygen sensors permanently.
