P0804

1-4 Upshift (Skip Shift) Lamp Control Circuit

Severity
Low
Driving
No driving restriction
System
Powertrain
Group
Transmission

A fault in the control circuit for the skip shift indicator lamp - the lamp that tells the driver the transmission is asking for a 1-4 upshift. The skip shift function itself may be working perfectly; what has failed is the circuit that lights the lamp.

Possible causes

  • CommonBlown indicator bulb, on vehicles with a bulb rather than an LED cluster
  • CommonWiring or connector fault to the lamp
  • PossibleFailed instrument cluster lamp driver
  • PossibleCorroded connector behind the cluster
  • RareFailed control module output

What you might notice

  • Skip shift lamp not lighting
  • Skip shift lamp permanently on
  • Check engine light on
  • No effect on how the car drives

What to check, in order

  1. Check whether the lamp lights during the ignition-on bulb check. If it never lights there, start with the bulb or the cluster.
  2. Check the wiring between the module and the cluster.
  3. Confirm the skip shift function itself still works before spending anything - this code concerns the lamp only.
  4. Check for P0803 stored alongside, which would point at the solenoid circuit instead.
