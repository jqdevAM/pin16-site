P0512

Starter Request Circuit

Severity
Medium
Driving
Drivable — book it in
System
Powertrain
Group
Vehicle speed control, idle control and auxiliary inputs

A fault in the starter request circuit - the circuit carrying the request to crank, from the key switch or start button to the module that authorises it. Depending on which way the fault goes the engine may refuse to crank, or may crank when it should not.

Possible causes

  • CommonFailed ignition switch or start button
  • CommonWiring or connector fault in the request circuit
  • CommonWorn ignition switch contacts
  • PossibleAftermarket alarm, immobiliser or remote start spliced into the circuit
  • RareFailed control module input

What you might notice

  • Engine will not crank
  • Intermittent no-crank, often when hot
  • Starter continuing to crank after release
  • Check engine light on

What to check, in order

  1. Watch the starter request state on the live data screen while someone turns the key or presses the button.
  2. Check the ignition switch. Worn contacts are the most common cause and typically fail intermittently before they fail completely.
  3. Ask whether an aftermarket alarm, immobiliser or remote start has been fitted - these are wired into exactly this circuit.
  4. Check the wiring between the switch and the module.
  5. A starter that keeps cranking after the key is released will destroy itself and the ring gear. If that is the symptom, disconnect the battery rather than waiting.
