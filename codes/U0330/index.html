U0330

Software Incompatibility with Tire Pressure Monitor Module

Severity
Medium
Driving
Drivable — book it in
System
Network and communication
Group
Network software

The software in the tyre pressure monitor module is not compatible with the rest of the vehicle. Tyre pressure monitoring will not work, so you get no warning of a slow puncture or an under-inflated tyre. The tyres themselves are unaffected - what you have lost is the warning, not the pressure.

Possible causes

  • CommonThe tyre pressure monitor module replaced but never coded to this vehicle
  • CommonUsed module fitted from a different vehicle or market
  • CommonModule not configured for the vehicle's tyre sizes and pressures after fitting
  • CommonSoftware update interrupted during programming
  • CommonWrong part number - sensor protocols and frequencies vary by market

What you might notice

  • Tyre pressure warning light on or flashing
  • Tyre pressure display blank or showing dashes
  • System reports no sensors found
  • No effect on how the car drives

What to check, in order

  1. Check all four tyre pressures with a gauge, including the spare, and keep checking them by hand until this is repaired. That restores what you have actually lost.
  2. Ask what was done. A module replacement, or a wheel and sensor change, immediately before this appeared is the explanation.
  3. Check the module is configured for the vehicle's actual tyre sizes and specified pressures.
  4. Check the part number against the market. Sensor radio frequencies and protocols differ between regions, so a module from another market will not work here.
  5. A tyre pressure warning light is an inspection failure in many jurisdictions regardless of whether the tyres are correctly inflated.
