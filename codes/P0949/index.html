P0949

Auto Shift Manual Adaptive Learning Not Complete

Severity
Medium
Driving
Drivable — book it in
System
Powertrain
Group
Transmission and control modules
Important. This is a procedure, not a part. If you have just replaced a clutch or disconnected the battery on one of these transmissions, running the adaptation is a required step rather than an optional refinement - skipping it is one of the most common reasons a correctly done repair still drives badly.

The transmission's adaptive learning has not finished. These transmissions learn where the clutch bites and where each gear engages, and they need that learned data to shift smoothly. This code means the learning procedure has not completed - usually because it was never run after a repair, or because the battery was disconnected and the learned values were lost.

Possible causes

  • CommonAdaptation procedure never run after a clutch or actuator repair
  • CommonBattery disconnected or replaced, clearing the learned values
  • CommonAdaptation started but interrupted before it completed
  • CommonAnother stored fault preventing adaptation from running
  • PossibleClutch worn beyond the range the module can adapt to
  • PossibleLow hydraulic pressure preventing the procedure completing

What you might notice

  • Jerky or harsh take-up when moving off
  • Slow or clumsy gear changes
  • Judder at low speed
  • Transmission warning message
  • Behaviour noticeably worse since a repair or a battery change

What to check, in order

  1. Ask what happened just before the symptoms started. A repair, a clutch replacement or a battery disconnection immediately before it appeared is the answer in most cases.
  2. Read all codes first. Adaptation will not complete while another fault is stored, so clear the underlying fault before attempting it.
  3. Run the adaptation procedure with the vehicle in the conditions the manufacturer specifies - usually a particular fluid temperature, engine idling, and the vehicle stationary and level.
  4. Let the procedure finish. Interrupting it leaves the transmission in exactly the state this code describes.
  5. If adaptation completes but the transmission still shifts badly, assess clutch wear - a worn clutch may be outside the range the module can adapt to.
