P0814

Transmission Range Display Circuit

Severity
Low
Driving
Drivable — book it in
System
Powertrain
Group
Transmission

A fault in the circuit that drives the gear position display - the PRNDL indicator that shows which gear you have selected. The transmission itself is generally unaffected; what has failed is the display of what it is doing.

Possible causes

  • CommonWiring or connector fault between the transmission module and the display
  • CommonFailed display or instrument cluster segment
  • PossibleFaulty transmission range sensor feeding the display
  • PossibleCorroded connector behind the cluster or in the console
  • RareFailed control module output

What you might notice

  • Gear position display blank, stuck or showing the wrong gear
  • Display segments missing
  • Check engine light on
  • Transmission otherwise behaving normally

What to check, in order

  1. Compare the displayed gear with the actual selected gear on the live data screen. If the module knows the right gear and the display shows the wrong one, the fault is in the display circuit.
  2. Check whether the transmission shifts correctly. If it does, this is a display fault and can be treated as minor.
  3. Inspect the connectors at the cluster and in the centre console.
  4. Check for range sensor codes stored alongside - those would mean the module itself has the wrong information.
  5. A display that shows the wrong gear is worth fixing even though it is minor. Selecting reverse when you believe you are in drive is an avoidable way to have an accident in a car park.
