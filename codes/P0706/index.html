P0706

Transmission Range Sensor Circuit Range/Performance

Severity
High
Driving
Drive only to a garage
System
Powertrain
Group
Transmission

The transmission range sensor is answering, but its reading does not agree with what the module expects - the reported selector position does not match the gear the transmission is actually in, or it changes when the selector has not moved. Usually this is a worn selector linkage or a sensor that has drifted out of adjustment rather than a dead sensor.

Possible causes

  • CommonRange sensor out of adjustment
  • CommonWorn selector cable or linkage
  • CommonWorn contacts inside the sensor giving an ambiguous position
  • PossibleCorroded connector or wiring
  • PossibleInternal transmission fault, so the actual gear does not match the selected one

What you might notice

  • Gear position display flickering or showing the wrong gear
  • Harsh or delayed engagement
  • Occasional failure to start
  • Transmission dropping into limp mode intermittently

What to check, in order

  1. Watch the reported gear position on the live data screen through the full selector travel, slowly. Look for a position that is briefly ambiguous between detents - that is the classic signature of worn sensor contacts.
  2. Check and adjust the sensor to the manufacturer's specification before replacing it.
  3. Check the selector cable for stretch and the linkage bushings for wear.
  4. Check whether the fault appears only when the transmission is hot. That points at the sensor rather than the linkage.
  5. Check for gear ratio codes stored alongside. Those would suggest the transmission genuinely is not in the gear it was told to be in.
