P2532

Ignition Switch Run Position Circuit High

Severity
High
Driving
Drivable — book it in
System
Powertrain
Group
Vehicle speed control, idle control and auxiliary inputs

The ignition switch run position circuit is reading high - typically shorted to voltage, or contacts stuck closed. The module sees the run position selected regardless of where the key actually is, so systems may stay powered when the car is switched off - which flattens the battery overnight.

Possible causes

  • CommonIgnition switch contacts stuck or welded closed
  • CommonWiring shorted to voltage
  • CommonCorrosion in a connector bridging adjacent pins
  • PossibleAftermarket alarm or remote start holding the circuit live
  • RareFailed control module input

What you might notice

  • Battery flat after standing overnight
  • Accessories staying on after the key is removed
  • Cooling fan or blower continuing to run
  • Engine continuing to run briefly after switch-off
  • Check engine light on

What to check, in order

  1. Watch the run position state with the key removed. A reading that still shows the position selected confirms the fault immediately.
  2. Unplug the switch and check whether the high reading persists at the harness.
  3. Inspect the connector for corrosion bridging adjacent pins.
  4. Ask whether an aftermarket alarm or remote start was fitted.
  5. If the battery is going flat overnight, this is the likely cause and worth fixing before replacing the battery.
