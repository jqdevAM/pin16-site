P0641

Sensor Reference Voltage "A" Circuit/Open

Severity
High
Driving
Drive only to a garage
System
Powertrain
Group
Computer output circuits and control module
Important. This is the single most useful thing to recognise about a car with a dozen sensor codes at once: one shared reference voltage explains all of them. Do not start buying sensors.

An open circuit or general fault in sensor reference voltage "A". The module supplies a regulated reference - typically 5 volts - to a whole group of sensors, and each of them reports by returning a fraction of it. When that reference is lost, every sensor sharing it goes silent at once. Expect a long list of unrelated-looking codes: throttle position, pedal position, pressure sensors, temperature sensors, all faulting together.

Possible causes

  • CommonOne sensor on the shared reference circuit failed internally and pulled the whole reference down
  • CommonWiring shorted or chafed on the reference circuit
  • CommonCorroded or water-ingressed connector on a sensor sharing the reference
  • PossibleReference circuit shorted to earth or to another voltage
  • PossibleFailed control module reference supply

What you might notice

  • A long list of sensor codes at once
  • Reduced power or limp mode
  • Engine running badly or not starting
  • Several gauges reading wrongly
  • Check engine light on

What to check, in order

  1. Fix this before diagnosing any of the sensors. Every sensor code stored alongside it is a consequence, and replacing those sensors will change nothing.
  2. List which sensors have faulted. They all share reference "A", and that list is a wiring diagram of where to look.
  3. Unplug the sensors on that reference circuit one at a time with the reference voltage on a meter. When the reference recovers, the sensor you have just unplugged is the fault.
  4. Inspect connectors for water and corrosion, which is the most common way a reference gets pulled down.
  5. Check the harness for chafe damage where the reference circuit runs.
  6. Suspect the control module only after every sensor on the circuit has been eliminated.
