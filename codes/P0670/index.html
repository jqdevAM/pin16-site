P0670

Glow Plug Module Control Circuit

Severity
Low
Driving
Drivable — book it in
System
Powertrain
Group
Computer output circuits and control module

A fault in the glow plug control module circuit. This module switches the heavy current the glow plugs need, and the engine module controls it. With the circuit faulty none of the plugs will heat, so cold starting suffers even if every plug is perfect.

Possible causes

  • CommonFailed glow plug
  • CommonCorroded connection at the plug
  • CommonFailed glow plug control module
  • PossibleDamaged wiring in the glow plug harness
  • PossibleBlown fuse or fusible link
  • PossibleSeized plug damaged during a previous removal
  • CommonWiring fault between the engine module and the glow plug module

What you might notice

  • Hard starting when cold
  • White smoke on a cold start
  • Rough running for the first minute from cold
  • Glow plug light behaving oddly
  • No symptom at all in warm weather

What to check, in order

  1. Test on a genuinely cold engine. In summer a diesel will often start acceptably with several dead glow plugs, which is why these faults go unnoticed until the first frost.
  2. Measure each glow plug individually. They fail one at a time, and the code may be set by just one of them.
  3. Inspect the connections at the plugs for corrosion - they sit in a hot, dirty part of the engine.
  4. Check the fuse or fusible link and the control module.
  5. Be aware that seized glow plugs are common on high-mileage engines and can break off during removal, which turns a cheap job into an expensive one. Worth knowing before starting rather than halfway through.
