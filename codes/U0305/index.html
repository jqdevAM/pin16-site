U0305

Software Incompatibility with Cruise Control Module

Severity
Low
Driving
No driving restriction
System
Network and communication
Group
Network software

The software in the cruise control module is not compatible with the rest of the vehicle. Cruise control will not be available. Nothing about the way the car drives or stops is affected - and on many vehicles this appears after cruise control has been retrofitted without the rest of the car being told about it.

Possible causes

  • CommonThe cruise control module replaced but never coded to this vehicle
  • CommonCruise control retrofitted without coding the vehicle's option list
  • CommonUsed module fitted from a different vehicle or specification
  • CommonSoftware update interrupted during programming
  • CommonWrong part number - adaptive and conventional cruise modules are not interchangeable

What you might notice

  • Cruise control will not engage
  • Cruise control warning message
  • Cruise control switches doing nothing
  • No effect on ordinary driving

What to check, in order

  1. Ask whether cruise control was retrofitted. Fitting the hardware without coding the vehicle to expect it is a very common cause of this code.
  2. Check whether the vehicle's option coding lists cruise control as fitted.
  3. Check the part number - adaptive cruise and conventional cruise modules look similar and are not interchangeable.
  4. Confirm ordinary driving is unaffected, in which case this can wait.
  5. This needs manufacturer-level coding rather than a replacement part.
