P0603

Internal Control Module Keep Alive Memory (KAM) Error

Severity
Medium
Driving
Drivable — book it in
System
Powertrain
Group
Computer output circuits and control module

Keep-alive memory in the control module has failed. This is the memory that survives the ignition being switched off - it holds the adaptations the module has learned about this particular engine over time. Losing it does not stop the car working, but the module has to relearn everything, so the car may run and shift noticeably worse for the first few journeys.

Possible causes

  • CommonLow or unstable supply voltage - a weak battery, a corroded earth, or a failing alternator makes a healthy module fail its own self-test
  • CommonCorroded or water-ingressed module connector
  • CommonWater reaching the module - many sit low in the engine bay or in a footwell
  • CommonSoftware update interrupted, or programming never completed
  • PossibleGenuine internal module failure
  • PossibleDamage from a jump start with reversed leads, or from arc welding on the vehicle
  • CommonBattery disconnected or gone flat, clearing the learned values
  • CommonBattery terminals loose, interrupting the permanent supply

What you might notice

  • Rough idle or poor running for the first few journeys after the fault
  • Shift quality noticeably worse
  • Learned settings lost
  • Check engine light on
  • Often improves on its own over a few days of driving

What to check, in order

  1. Check the permanent battery feed to the module, and the battery terminals. Keep-alive memory depends on an uninterrupted supply, so a loose terminal wipes it every time the car is started.
  2. Ask whether the battery was disconnected or went flat. That explains the code without anything being wrong.
  3. Drive it normally for a few days and see whether it settles. Adaptations rebuild themselves with use.
  4. Check whether an adaptation reset is specified after repair, so the module starts from a known state rather than a half-learned one.
  5. Check battery voltage, the terminals and the earth straps before anything else. An unstable supply makes a perfectly good module fail its own self-test, and that is the most common reason this code appears on a module that turns out to be fine.
  6. Look for water. Check the module's location and its connector for damp, corrosion and green residue - a blocked bulkhead or sunroof drain is a frequent cause.
  7. Clear the code and see whether it returns. A single occurrence during a voltage dip is not the same as a module that fails every time it is powered up.
  8. Ask what was done recently. An interrupted programming session, a jump start, or welding on the vehicle can all damage or confuse a module.
  9. Treat module replacement as the last step, not the first. A replacement needs programming and coding to the vehicle, so a wrong guess is expensive twice over.
