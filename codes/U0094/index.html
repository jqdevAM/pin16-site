U0094

Reserved by Document

Severity
Low
Driving
No driving restriction
Important. Nothing is wrong with your scan tool for showing this. The number exists in the standard's numbering scheme but was deliberately left without a meaning.

This code number is reserved in the standard and has no assigned meaning. SAE J2012 sets aside blocks of numbers for future use, and this is one of them - so there is no fault it corresponds to. If a scan tool has reported it, the likeliest explanations are that the manufacturer has used the reserved number for something of their own, or that the code was misread.

Possible causes

  • CommonManufacturer using a reserved number for a definition of their own
  • CommonScan tool misreading or mis-decoding a response
  • PossibleCommunication error producing a corrupted code number

What you might notice

  • A code reported with no recognised description
  • Usually appears alongside other codes rather than alone

What to check, in order

  1. Read the codes again after clearing them, and see whether this one returns. A corrupted read will not come back; a real manufacturer-specific code will.
  2. Check the vehicle manufacturer's own documentation. A reserved number in the generic standard may well be defined in theirs.
  3. Deal with the other stored codes first. A reserved number rarely tells you anything on its own.
