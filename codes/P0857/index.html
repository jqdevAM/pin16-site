P0857

Traction Control Input Signal Range/Performance

Severity
Medium
Driving
Drivable — book it in
System
Powertrain
Group
Transmission

The traction control input signal is present but implausible - it does not agree with what the transmission module knows from its own speed sensors. One of the two sources is wrong, and the module cannot tell which.

Possible causes

  • CommonWheel speed sensor fault upstream
  • CommonMismatched tyre sizes or a space-saver spare fitted
  • PossibleFault in the ABS or traction control module
  • PossibleTransmission output speed sensor fault
  • PossibleNon-standard wheel or tyre sizes changing the calculation

What you might notice

  • Traction control warning light on
  • Traction control activating when it should not
  • Transmission shifting oddly under acceleration
  • ABS warning light on as well

What to check, in order

  1. Check the tyres. A space-saver spare, mismatched sizes or badly uneven wear makes wheel speeds genuinely disagree, and that is a far more common cause than any electrical fault.
  2. Read the ABS module for wheel speed sensor codes.
  3. Compare the individual wheel speeds on the live data screen while driving straight on a level road - they should be close to identical.
  4. Check the transmission output speed sensor reading against road speed.
  5. Ask whether non-standard wheels or tyres have been fitted.
