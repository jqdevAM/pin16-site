P2106

Throttle Actuator Control System - Forced Limited Power

Severity
Critical
Driving
Drive only to a garage
System
Powertrain
Group
Fuel and air metering
Important. A vehicle that can enter reduced-power mode at any moment is a hazard when joining fast-moving traffic. Drive it to be repaired, not on a journey that depends on it.

The module has limited engine power deliberately. It found a fault in the throttle system and decided it can no longer trust full throttle authority, so it has capped what the engine will deliver. The restriction is the protection; the cause is a separate code.

Possible causes

  • CommonAnother throttle or pedal fault already stored - this code is the module's response to it
  • CommonThrottle or pedal position sensor disagreement
  • CommonCarbon making the throttle plate stiff
  • CommonWiring or connector fault on a throttle or pedal circuit
  • PossibleLow or unstable supply voltage
  • PossibleFailed throttle actuator control module

What you might notice

  • Sudden loss of power - reduced-power mode
  • Engine will not rev beyond a low limit
  • Rough or unstable idle
  • Warning light for reduced engine power
  • Engine may not start

What to check, in order

  1. Read all codes. This one records what the module did, not what went wrong - the fault that triggered it is stored alongside, and that is the one to diagnose.
  2. Check battery voltage and the earth connections. An unstable supply produces sensor disagreements that look like component failures.
  3. Inspect the throttle body for carbon and the connectors for corrosion.
  4. Compare commanded against actual throttle position on the live data screen.
