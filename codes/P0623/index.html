P0623

Generator Lamp Control Circuit

Severity
Low
Driving
Drivable — book it in
System
Powertrain
Group
Computer output circuits and control module

A fault in the generator lamp control circuit - the circuit that drives the battery warning lamp itself. Unlike the L-terminal circuit, this one has no part in exciting the alternator, so charging is generally unaffected. What is lost is the warning: a genuine charging fault might not light the lamp.

Possible causes

  • CommonBlown warning lamp bulb
  • CommonWiring or connector fault between the module and the cluster
  • PossibleFailed instrument cluster lamp driver
  • PossibleCorroded connector behind the cluster
  • RareFailed control module output

What you might notice

  • Battery warning light not working
  • Battery warning light permanently on
  • Check engine light on
  • Charging otherwise normal

What to check, in order

  1. Check whether the lamp lights during the ignition-on bulb check.
  2. Measure charging voltage to confirm the charging system itself is healthy.
  3. Check the wiring between the module and the cluster.
  4. Treat this as a warning system fault - but do not ignore it, because it means a real charging failure may go unannounced.
