P0589

Cruise Control Multi-Function Input "B" Circuit

Severity
Low
Driving
No driving restriction
System
Powertrain
Group
Vehicle speed control, idle control and auxiliary inputs

A fault in the cruise control multi-function input "B" circuit. Several cruise commands usually share one wire, each sending a different voltage, so a single fault here can take out set, resume and cancel together.

Possible causes

  • CommonFailed cruise control switch or stalk
  • CommonWiring fault in the steering column or console
  • CommonDamaged clock spring, on steering-wheel-mounted controls
  • CommonCorroded or disturbed connector
  • PossibleBrake or clutch switch fault preventing cruise from engaging
  • RareFailed control module input

What you might notice

  • Cruise control will not engage
  • Cruise control cancelling on its own
  • Set, resume or cancel not responding
  • Cruise warning message
  • Check engine light on

What to check, in order

  1. Watch the cruise control switch states on the live data screen while operating each control.
  2. Check the brake and clutch switches. Cruise control will not engage while the module thinks the brake is pressed, so a brake switch fault presents as a cruise control fault.
  3. On steering-wheel controls, suspect the clock spring - horn or airbag faults alongside confirm it.
  4. Inspect the connector if the column or console has been worked on.
  5. Confirm ordinary driving is unaffected, in which case this can wait.
