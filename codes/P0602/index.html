P0602

Control Module Programming Error

Severity
High
Driving
Drive only to a garage
System
Powertrain
Group
Computer output circuits and control module

The control module has not been programmed, or its programming did not complete. This is not a hardware failure: the module is fine and its software is missing or incomplete. It almost always follows a module replacement or a software update - most often one that was interrupted because battery voltage fell part way through.

Possible causes

  • CommonModule replaced and never programmed
  • CommonProgramming session interrupted, usually by falling battery voltage
  • CommonWrong software loaded for the vehicle
  • CommonUsed module fitted from a different vehicle or specification
  • PossiblePoor connection during programming
  • RareGenuine internal module failure

What you might notice

  • Engine will not start
  • Limp mode
  • Vehicle behaving as though badly configured
  • Fault present since a repair or a software update
  • Check engine light on

What to check, in order

  1. Ask what was done. A module replacement or a software update immediately before this appeared is the explanation.
  2. Re-run the programming with a battery support unit connected so the voltage cannot fall again. An interrupted session is usually recoverable.
  3. Check the software is the correct one for this vehicle's model year, market and engine.
  4. Do not replace the module. Programming is the repair, and a second unprogrammed module will sit in exactly the same state.
  5. This needs manufacturer-level programming. A generic scan tool cannot do it, and neither can Pin16's coding lane, which writes documented parameters rather than module software.
