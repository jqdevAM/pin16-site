P0597

Thermostat Heater Control Circuit/Open

Severity
Low
Driving
Drivable — book it in
System
Powertrain
Group
Vehicle speed control, idle control and auxiliary inputs

An open circuit in the thermostat heater control. Some engines use a thermostat with a small electric heater in it, so the module can make it open earlier than its normal temperature would - running the engine hotter for economy at light load and cooler under heavy load. With the heater circuit open, the thermostat simply behaves like an ordinary one.

Possible causes

  • CommonFailed thermostat heater element
  • CommonCorroded connector or damaged wiring
  • PossibleBlown fuse on the circuit
  • PossibleThermostat stuck, so heating it changes nothing
  • RareFailed control module driver

What you might notice

  • Engine running cooler than normal
  • Heater not as warm as it should be
  • Worse fuel economy
  • Temperature gauge slow to rise
  • Check engine light on

What to check, in order

  1. Watch the coolant temperature during a normal drive. An engine that never reaches its usual operating temperature points at the thermostat itself rather than the heater circuit.
  2. Check the connector and wiring at the thermostat.
  3. Measure the heater element resistance against specification.
  4. Check the fuse for the circuit.
  5. Note that this heater does not warm the engine. It warms the thermostat so it opens earlier than it otherwise would, which the module uses to fine-tune running temperature.
