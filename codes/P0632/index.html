P0632

Odometer Not Programmed - ECM/PCM

Severity
Medium
Driving
Drivable — book it in
System
Powertrain
Group
Computer output circuits and control module
Important. Odometer adjustment is regulated work. Have it done by a franchised dealer or a properly authorised specialist who will record it, rather than by anyone offering to set it to a number of your choosing.

The odometer value has not been written to the engine control module. Several modules hold a mileage figure and compare them, so that a replaced instrument cluster cannot quietly reduce a vehicle's recorded mileage. A blank value after a module or cluster replacement is normal and is fixed by writing it.

Possible causes

  • CommonModule replaced and never configured to this vehicle
  • CommonUsed module fitted from a different vehicle or specification
  • CommonProgramming or coding session interrupted
  • CommonWrong part number for the market, model year or engine variant
  • CommonConfiguration data not transferred during a module swap
  • PossibleAftermarket tuning device altering what the module reports

What you might notice

  • Check engine light on
  • Odometer blank or disputed between displays
  • Fault present since a cluster or module replacement
  • Usually no drivability symptom

What to check, in order

  1. Write the correct mileage to the module. That is the repair.
  2. Expect this to require proof of ownership and to be recorded. Odometer programming is regulated in most jurisdictions precisely because of what it could otherwise be used for.
  3. If the recorded mileage does not match the vehicle's history, do not proceed until that is explained - this is one of the mechanisms by which mileage fraud is detected.
  4. Ask what was done to the vehicle recently. These codes follow work; they do not appear on their own.
  5. Read the software and part numbers of the modules involved and compare them against the vehicle's build specification.
  6. Do not replace the module. The hardware is almost always right and the configuration is missing.
  7. Expect manufacturer-level programming. A generic scan tool can read these codes but cannot resolve them.
  8. If a used module was fitted, check whether it can be transferred to this vehicle at all - some are locked to their original VIN.
