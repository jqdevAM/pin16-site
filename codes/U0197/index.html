U0197

Lost Communication With Telephone Control Module

Severity
Medium
Driving
Drivable — book it in
System
Network and communication
Group
Network communication
Important. The emergency call function matters more than the entertainment features on the same module. If the vehicle is fitted with automatic crash notification, this fault means it will not call for help after a collision.

The control module has stopped receiving messages from the telephone control module. Hands-free calling, connected services and remote app functions will not work. On a vehicle fitted with automatic crash notification - eCall in Europe, and its equivalents elsewhere - this is also the module that calls for help automatically after a serious collision, and that will not happen while this fault is present.

Possible causes

  • CommonLow battery voltage or a discharged battery, dropping modules off the bus
  • CommonBlown fuse or corroded earth on the supply to the telephone control module
  • PossibleCorroded or water-ingressed connector
  • PossibleDamaged, chafed or corroded bus wiring
  • PossibleFailed module
  • PossibleModule backup battery flat or expired
  • PossibleNetwork service withdrawn - older modules on retired mobile networks stop working permanently

What you might notice

  • Hands-free calling unavailable
  • Connected or app-based services not working
  • Emergency call warning light or message
  • Vehicle reports no network
  • No effect on how the car drives

What to check, in order

  1. Do not assume automatic crash notification is working. If the vehicle has an emergency call button and it shows a fault, treat that as the important part of this code and carry a phone.
  2. Check battery voltage and state of charge before anything else. A weak or failing battery drops modules off the bus and sets lost-communication codes with no wiring fault at all - this is the single most common false lead in this whole family.
  3. Check the fuses, earths and connector for the telephone control module.
  4. Consider the vehicle's age. Telematics modules built for 2G or 3G networks stopped working when those networks were switched off, and no repair brings them back - the module is fine, the network is gone.
  5. Check whether the module has its own backup battery. These expire and are a common cause of emergency call faults.
