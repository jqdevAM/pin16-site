P0720

Output Speed Sensor Circuit

Severity
High
Driving
Drive only to a garage
System
Powertrain
Group
Transmission

A fault in the circuit for the output speed sensor, which tells the module how fast the transmission output shaft is turning. That matters because it is the module's measure of road speed and the other half of every gear ratio calculation. Without it the module cannot verify what the transmission is doing, so it will usually stop shifting normally and hold a single gear.

Possible causes

  • CommonFailed speed sensor
  • CommonCorroded connector or wiring damage at the sensor
  • CommonMetal debris on the sensor tip, from internal wear
  • PossibleDamaged or contaminated reluctor ring the sensor reads
  • PossibleInternal transmission harness failure
  • PossibleSensor air gap wrong after a previous repair

What you might notice

  • Transmission stuck in one gear - limp mode
  • Harsh or erratic shifting
  • Speedometer inoperative or erratic on vehicles that take speed from this sensor
  • Cruise control unavailable
  • Check engine light on

What to check, in order

  1. Watch the speed readings on the live data screen while driving. Input and output speed should track each other in a fixed ratio in each gear; one that reads zero or jumps about names itself.
  2. Inspect the sensor tip for a coating of metal filings. Debris here is not just the fault - it is evidence of internal wear that will need addressing.
  3. Check the connector and wiring at the sensor for corrosion and chafing.
  4. Check the fluid level and condition.
  5. If the sensor is accessible, measure its resistance against specification.
  6. Where the sensor is internal, eliminate the external wiring and the case connector before dropping the pan.
