P0154

O2 Sensor Circuit No Activity Detected (Bank 2 Sensor 1)

Severity
Medium
Driving
Drivable — book it in
System
Powertrain
Group
Fuel and air metering

The module is seeing no activity at all from the upstream oxygen sensor on bank 2 - the signal is flat rather than wrong. Usually this means the circuit is open, the sensor has died completely, or the sensor never reached operating temperature because its heater has failed.

Possible causes

  • CommonOpen circuit in the sensor wiring - broken wire or unplugged connector
  • CommonFailed oxygen sensor
  • CommonFailed sensor heater, so the sensor never warms enough to work
  • PossibleBlown fuse on the sensor heater circuit
  • PossibleCorroded connector

What you might notice

  • Check engine light on
  • Worse fuel economy - the module falls back to a default fuel calculation
  • Rough running
  • Failed emissions test

What to check, in order

  1. Check the connector is properly seated. A sensor unplugged during other work is a genuinely common cause.
  2. Check the fuse for the oxygen sensor heater circuit before anything else - it is quick and cheap to eliminate.
  3. Look for a heater circuit code stored alongside this one. If present, the heater is the cause and the sensor is not warming up.
  4. Check continuity of the sensor wiring back to the module.
  5. Replace the sensor once wiring, fuse and connector have been eliminated.
