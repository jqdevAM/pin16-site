P0950

Auto Shift Manual Control Circuit

Severity
Low
Driving
No driving restriction
System
Powertrain
Group
Transmission and control modules

A fault in the auto shift manual control circuit - the circuit carrying the driver's manual gear change requests. Automatic shifting continues to work; what is lost is the ability to select gears yourself.

Possible causes

  • CommonFailed shift switch or paddle assembly
  • CommonWiring fault in the console or steering column
  • CommonDamaged clock spring on steering-wheel-mounted paddles
  • PossibleCorroded or disturbed connector
  • RareFailed control module input

What you might notice

  • Manual mode not responding
  • Paddles or lever ignored
  • Manual mode unavailable
  • Check engine light on

What to check, in order

  1. Watch the switch state on the live data screen while operating the control.
  2. Check whether both directions fail. Both failing points at shared wiring or the clock spring rather than a switch.
  3. Inspect the connector if the console or column has been worked on.
  4. On steering-wheel paddles, check for horn or airbag faults alongside, which confirm a clock spring problem.
  5. Confirm automatic shifting is normal, in which case this can wait.
