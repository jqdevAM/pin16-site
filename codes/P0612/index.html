P0612

Fuel Injector Control Module Relay Control

Severity
High
Driving
Drive only to a garage
System
Powertrain
Group
Computer output circuits and control module

A fault in the relay control circuit for the fuel injector control module. Some engines - particularly diesels with piezo injectors - use a separate module to drive the injectors, and it has its own power relay. Without it the injectors cannot be driven and the engine will not run.

Possible causes

  • CommonFailed relay
  • CommonCorroded relay socket or fuse box connections
  • CommonWiring fault between the module and the relay
  • CommonWater ingress into the fuse box
  • PossibleBlown fuse
  • RareFailed control module driver

What you might notice

  • Engine will not start
  • Engine cutting out
  • Severe misfire
  • Loss of power
  • Check engine light on

What to check, in order

  1. Swap the relay with an identical one from elsewhere in the box and see whether the fault follows it. It costs nothing and is the fastest test available.
  2. Inspect the relay socket for corrosion, heat damage and spread terminals - a discoloured socket means the relay has been running hot.
  3. Check the fuse for the circuit.
  4. Check the fuse box for water ingress, particularly if it is mounted low or in the engine bay.
  5. Check the wiring between the module and the relay.
