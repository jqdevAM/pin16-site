P0856

Traction Control Input Signal

Severity
Medium
Driving
Drivable — book it in
System
Powertrain
Group
Transmission

A fault in the traction control input signal to the transmission module. When the traction control system detects wheelspin it asks for reduced torque and, on many vehicles, for the transmission to hold or change gear. Without that signal the two systems cannot coordinate, so traction control may be disabled or less effective.

Possible causes

  • CommonWiring or bus fault between the traction control and transmission modules
  • CommonFault in the ABS or traction control module itself
  • PossibleCorroded connector at either module
  • PossibleWheel speed sensor fault upstream, so the signal is missing at source
  • PossibleLow battery voltage dropping a module off the bus

What you might notice

  • Traction control warning light on
  • Traction control inoperative
  • Transmission not responding to wheelspin
  • ABS warning light on as well
  • Check engine light on

What to check, in order

  1. Read the ABS and traction control modules as well. The fault is usually there, and this code is only the transmission module noticing.
  2. Check battery voltage and state of charge - a weak battery drops modules off the bus and produces communication faults with no wiring problem at all.
  3. Look for wheel speed sensor codes, which would explain a missing signal at source.
  4. Inspect the connectors at both modules.
  5. Assume traction control is not working and drive accordingly, particularly in the wet or on loose surfaces.
