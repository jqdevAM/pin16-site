P2413

Exhaust Gas Recirculation System Performance

Severity
Medium
Driving
Drivable — book it in
System
Powertrain
Group
Auxiliary emission controls

The EGR system as a whole is not performing to specification. The module has compared what the system should be doing against what it measured and found the difference too large to accept, without pinning it on one component. On a high-mileage engine this is usually the cumulative result of soot everywhere in the system rather than one failed part.

Possible causes

  • CommonCarbon build-up throughout the EGR valve, passages and cooler
  • CommonEGR valve not sealing or not opening fully
  • PossibleBlocked EGR cooler
  • PossibleFaulty EGR position or pressure sensor skewing the module's measurement
  • PossibleIntake manifold leak upsetting the pressures the module relies on
  • PossibleFaulty EGR throttle on engines that use one

What you might notice

  • Check engine light on
  • Rough idle
  • Reduced power
  • Increased exhaust smoke on a diesel
  • Failed emissions test

What to check, in order

  1. Treat this as a whole-system inspection rather than a single-part diagnosis. Remove the valve, look into the passages, and check the cooler if the engine has one.
  2. Clean everything in the EGR path, not just the valve. Cleaning the valve alone and leaving a blocked passage is the most common reason this code comes back.
  3. Check for intake leaks. The module infers EGR flow from pressures, so a leak makes a healthy system measure badly.
  4. Compare commanded against actual EGR position on the live data screen.
  5. Check whether an adaptation reset is specified after cleaning.
  6. Look for other stored codes first. A sensor code alongside this one usually names the real fault.
