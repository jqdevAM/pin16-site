P0129

Barometric Pressure Too Low

Severity
Low
Driving
Drivable — book it in
System
Powertrain
Group
Fuel and air metering

The barometric pressure reading is below what the module considers possible. Barometric pressure tells the module how dense the air is, which is how it compensates fuelling for altitude and weather. On most vehicles this reading comes from the manifold pressure sensor, measured with the engine stopped, so a manifold pressure fault and a barometric fault are usually the same fault.

Possible causes

  • CommonFailed manifold or barometric pressure sensor
  • CommonVacuum reaching the sensor when it should be reading atmospheric pressure - a hose routed or connected wrongly after other work
  • PossibleWiring or connector fault at the sensor
  • RareGenuinely very high altitude, beyond the range the module was calibrated for

What you might notice

  • Reduced power
  • Rich or lean running, especially noticeable at altitude
  • Poor fuel economy
  • Check engine light on

What to check, in order

  1. Read the barometric value at key-on with the engine off and compare it against the local weather report. At sea level expect roughly 100 kPa, falling with altitude; a reading well below what the weather says is the sensor, not the weather.
  2. Check for a manifold pressure code stored alongside. The two normally share one sensor, so fixing that fixes this.
  3. Check the vacuum hose routing if anything was recently worked on. A sensor that should read atmospheric pressure but has been plumbed into manifold vacuum reads low all the time.
  4. Note the altitude the vehicle actually lives at before condemning anything. This code is occasionally correct.
