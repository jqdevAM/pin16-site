P0904

Gate Select Position Circuit

Severity
High
Driving
Drive only to a garage
System
Powertrain
Group
Transmission and control modules

A fault in the gate select position circuit. Inside an automated manual gearbox the selector shaft moves on two axes, exactly as a driver's hand does: across the gate to choose which pair of gears, then fore or aft to engage one. This code concerns the sensor that reports the across-the-gate position. Without it the module cannot tell which gear pair it has selected.

Possible causes

  • CommonFailed gate select position sensor
  • CommonCorroded or damaged connector at the gearbox
  • CommonWiring damage in the actuator harness
  • CommonSensor not calibrated after a repair
  • PossibleLoss of reference voltage or earth
  • PossibleWater ingress at the gearbox connector

What you might notice

  • Transmission will not select a gear
  • Car stuck in neutral
  • Gear display blank or wrong
  • Transmission warning message
  • Check engine light on

What to check, in order

  1. Watch the gate select position on the live data screen while the module attempts a gear change. A reading that does not move identifies the fault immediately.
  2. Check the reference voltage and earth at the sensor before condemning it.
  3. Inspect the connector at the gearbox for corrosion and water.
  4. Check whether the transmission needs its position calibration re-running - this is routine after any actuator work.
  5. Read all codes. Gate select and gear shift codes together usually point at a shared supply, earth or connector.
