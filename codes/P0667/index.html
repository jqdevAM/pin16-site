P0667

PCM/ECM/TCM Internal Temperature Sensor Range/Performance

Severity
Medium
Driving
Drivable — book it in
System
Powertrain
Group
Computer output circuits and control module

The module's internal temperature sensor is answering, but the value is not plausible - it does not change as the module warms up, or it disagrees with ambient conditions.

Possible causes

  • CommonModule mounted where it gets little airflow, or a blocked cooling path
  • CommonA shorted output making the module work far harder than it should
  • CommonCorroded connector causing high resistance and local heating
  • CommonFailed internal temperature sensor
  • PossibleVery high ambient temperature combined with heavy load
  • PossibleGenuine internal module failure

What you might notice

  • Check engine light on
  • Limp mode in some cases
  • Often no symptom the driver notices

What to check, in order

  1. Compare the reported internal temperature with ambient on a vehicle that has stood overnight - they should be close.
  2. Read all codes for an over-temperature code stored alongside.
  3. Check the module connector and its supply voltage before concluding the module is at fault.
