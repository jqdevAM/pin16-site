P2107

Throttle Actuator Control Module Processor

Severity
Critical
Driving
Drive only to a garage
System
Powertrain
Group
Fuel and air metering
Important. A vehicle that can enter reduced-power mode at any moment is a hazard when joining fast-moving traffic. Drive it to be repaired, not on a journey that depends on it.

The throttle actuator control module has failed its own processor self-test. As with all internal module codes, an unstable supply voltage makes healthy hardware fail this test, so the electrical supply has to be eliminated before the module is condemned.

Possible causes

  • CommonLow or unstable supply voltage - a weak battery, a corroded earth, a failing alternator
  • CommonCorroded or water-ingressed module connector
  • CommonWater reaching the module
  • PossibleSoftware update interrupted or programming never completed
  • PossibleGenuine internal module failure

What you might notice

  • Sudden loss of power - reduced-power mode
  • Engine will not rev beyond a low limit
  • Rough or unstable idle
  • Warning light for reduced engine power
  • Engine may not start

What to check, in order

  1. Check battery voltage, the terminals and the earth straps before anything else. An unstable supply is the most common reason a module fails its own self-test and turns out to be fine.
  2. Look for water at the module and its connector.
  3. Clear the code and see whether it returns. A single occurrence during a voltage dip is not the same as a module that fails every time it powers up.
  4. Treat module replacement as the last step. A replacement needs programming and coding to the vehicle, so a wrong guess is expensive twice over.
