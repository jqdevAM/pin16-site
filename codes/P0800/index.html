P0800

Transfer Case Control System (MIL Request)

Severity
Medium
Driving
Drivable — book it in
System
Powertrain
Group
Transmission
Important. If your scan tool cannot read the transfer case module, this code tells you almost nothing. That is a limitation of the tool, not a sign the fault is minor.

This is not a fault in itself. It is the transfer case control module asking for the check engine light to be switched on because it has stored a fault of its own. The real code sits inside the transfer case module and that is what has to be read - this one names no component and will clear when the actual fault is fixed.

Possible causes

  • CommonA fault stored in the transfer case control module - this code only reports that one exists

What you might notice

  • Check engine light on
  • Four-wheel drive not engaging or disengaging
  • Four-wheel drive warning light on
  • Often no symptom at all

What to check, in order

  1. Read the transfer case control module, not just the engine module. Many basic scan tools only read the engine module, which is why this code so often appears alone with nothing to explain it.
  2. The real code will be stored in the transfer case module. Diagnose that one.
  3. Check the transfer case fluid level and condition while you are underneath.
  4. Do not replace parts on the strength of this code alone.
