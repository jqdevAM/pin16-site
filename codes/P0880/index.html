P0880

TCM Power Input Signal

Severity
High
Driving
Drive only to a garage
System
Powertrain
Group
Transmission

A fault in the power supply signal to the transmission control module. The module is monitoring its own supply voltage and does not like what it sees. Transmission modules need a stable supply to drive solenoids accurately, so a supply problem shows up as poor shift quality long before the module actually stops working.

Possible causes

  • CommonWeak or failing battery
  • CommonCorroded earth strap or module earth point
  • CommonCorroded or loose battery terminals
  • CommonCharging system fault - failing alternator
  • PossibleBlown fuse or failing relay in the module supply
  • PossibleDamaged supply wiring

What you might notice

  • Harsh or erratic shifting
  • Transmission dropping into limp mode
  • Other electrical warning lights at once
  • Slow cranking
  • Check engine light on

What to check, in order

  1. Check battery voltage, state of charge and the terminals first. This is the same false lead that dominates communication codes, and it is genuinely the cause more often than any module fault.
  2. Check the charging system output with the engine running.
  3. Clean and check the module earth points. Corroded earths cause voltage problems that look exactly like a failed module.
  4. Check the supply fuses and relays.
  5. Do not order a control module on the strength of a power supply code. The module is reporting a problem, not necessarily having one.
