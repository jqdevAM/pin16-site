P0911

Gate Select Actuator Circuit Range/Performance

Severity
High
Driving
Drive only to a garage
System
Powertrain
Group
Transmission and control modules

The gate select actuator circuit is electrically sound but the actuator is not performing as expected - slow to move, not reaching position, or drawing the wrong current. The problem is mechanical or hydraulic rather than electrical.

Possible causes

  • CommonLow hydraulic pressure on a hydraulically actuated system
  • CommonWorn or failing actuator
  • CommonSticking selector mechanism inside the gearbox
  • CommonCalibration lost or never performed
  • PossibleHigh resistance in the wiring weakening the drive
  • PossibleContaminated hydraulic fluid causing valves to stick

What you might notice

  • Slow gear changes
  • Some gears unavailable
  • Transmission dropping into neutral
  • Transmission warning message
  • Check engine light on

What to check, in order

  1. Check hydraulic pressure first if the system is hydraulically actuated. A slow actuator is far more often a pressure problem than a failed motor.
  2. Run the calibration procedure.
  3. Watch commanded against actual position on the live data screen through a full sweep.
  4. Check the hydraulic fluid level and condition.
  5. Check the wiring for high resistance before replacing the actuator.
