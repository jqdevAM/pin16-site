P2630

O2 Sensor Pumping Current Trim Circuit Low (Bank 2 Sensor 1)

Severity
Medium
Driving
Drivable — book it in
System
Powertrain
Group
Computer output circuits and control module
Important. Never swap the connector from an old wideband oxygen sensor onto a new one. The connector carries the sensor's individual calibration, and mixing them gives the module the wrong correction for the sensor it is actually reading.

A fault in the oxygen sensor pumping current trim circuit on bank 2 - a low reading, usually a short to earth or an open circuit. Every wideband oxygen sensor is slightly different, so each is supplied with a calibration value - usually a resistor built into its own connector - that tells the module how to interpret it. This circuit reads that value, and without it the module cannot trust the sensor's readings.

Possible causes

  • CommonCorroded or water-ingressed connector at the sensor
  • CommonDamaged calibration resistor in the sensor connector
  • CommonWrong or aftermarket sensor fitted
  • CommonWiring damaged by exhaust heat or chafing
  • PossibleFailed wideband oxygen sensor
  • RareFailed control module input

What you might notice

  • Check engine light on
  • Worse fuel economy
  • Failed emissions test
  • Fuel trim stuck at a default value
  • Rough running in some conditions

What to check, in order

  1. Inspect the sensor connector closely. The calibration resistor is inside it on most designs, so a damaged or corroded connector destroys the calibration even though the sensor is fine.
  2. Ask whether a non-original sensor was fitted. A sensor supplied without its matched connector, or a cheap substitute, sets exactly this code.
  3. Check the harness where it passes near the exhaust for heat and chafe damage.
  4. Do not cut and splice a wideband sensor connector. The calibration lives in it, and joining the wires to a different plug loses it.
  5. Check both banks - both faulting together points at a shared circuit rather than two failed sensors.
