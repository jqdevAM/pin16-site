P0653

Sensor Reference Voltage "B" Circuit High

Severity
High
Driving
Drive only to a garage
System
Powertrain
Group
Computer output circuits and control module

Sensor reference voltage "B" is reading high - the regulated supply to a group of sensors is above where it should be, usually because the circuit has been shorted to a higher voltage or has lost its earth. Sensors on that reference will report values that are too high across the board.

Possible causes

  • CommonReference circuit shorted to battery voltage or to another supply
  • CommonChafed harness bridging the reference to a supply wire
  • CommonWater or corrosion in a connector bridging adjacent pins
  • PossibleDamage from previous work - a probe pushed into the wrong pin, or a jump start error
  • PossibleFailed control module reference supply

What you might notice

  • Many sensor codes at once, most reading high
  • Limp mode or reduced power
  • Engine running badly
  • Check engine light on

What to check, in order

  1. Fix the reference before diagnosing any sensor stored alongside it.
  2. Look for a short to a supply wire. A reference sitting above its regulated value has to be getting voltage from somewhere.
  3. Inspect connectors for corrosion bridging adjacent pins.
  4. Check the harness for chafe damage where the reference runs alongside supply wires.
  5. Ask what work was done recently. Back-probing the wrong pin or a jump start with reversed leads can damage a reference circuit permanently.
