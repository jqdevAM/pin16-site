P0585

Cruise Control Multi-Function Input "A"/"B" Correlation

Severity
Medium
Driving
Drivable — book it in
System
Powertrain
Group
Vehicle speed control, idle control and auxiliary inputs

The two cruise control multi-function inputs disagree. Two circuits are used so that a single failure can be caught, and this code is that check working - one of the pair is wrong and the module cannot tell which, so it disables cruise control rather than act on an input it cannot trust.

Possible causes

  • CommonFailed cruise control switch or stalk
  • CommonWiring fault in the steering column or console
  • CommonDamaged clock spring, on steering-wheel-mounted controls
  • CommonCorroded or disturbed connector
  • PossibleBrake or clutch switch fault preventing cruise from engaging
  • RareFailed control module input

What you might notice

  • Cruise control will not engage
  • Cruise control cancelling on its own
  • Set, resume or cancel not responding
  • Cruise warning message
  • Check engine light on

What to check, in order

  1. Watch both inputs together while operating each control. The one that does not follow the other is the fault.
  2. Watch the cruise control switch states on the live data screen while operating each control.
  3. Check the brake and clutch switches. Cruise control will not engage while the module thinks the brake is pressed, so a brake switch fault presents as a cruise control fault.
  4. On steering-wheel controls, suspect the clock spring - horn or airbag faults alongside confirm it.
  5. Inspect the connector if the column or console has been worked on.
  6. Confirm ordinary driving is unaffected, in which case this can wait.
