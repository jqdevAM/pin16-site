P0406

Exhaust Gas Recirculation Sensor "A" Circuit High

Severity
Medium
Driving
Drivable — book it in
System
Powertrain
Group
Auxiliary emission controls

EGR sensor "A" is reporting a voltage above the range the module accepts - typically shorted to voltage or an open earth. This sensor tells the module where the EGR valve actually is, or how much gas is actually flowing. Without a believable reading the module cannot verify what the valve is doing, so it disables EGR control. Sensor "A" is the manufacturer's designation, not a physical location; the vehicle's own documentation says which sensor that is.

Possible causes

  • CommonWiring fault on the sensor "A" signal circuit
  • CommonCorroded or water-ingressed connector at the sensor
  • CommonFailed EGR position or pressure sensor
  • PossibleSplit or blocked hoses to a differential pressure sensor
  • PossibleLoss of the 5 volt reference or the sensor earth
  • RareFaulty control module

What you might notice

  • Check engine light on
  • EGR system disabled
  • Failed emissions test
  • Rough idle in some cases
  • Frequently no symptom the driver notices

What to check, in order

  1. Check the sensor connector for corrosion and water. This is the most common cause of both a stuck-high reading and an intermittent one.
  2. Measure the reference voltage at the sensor with the ignition on. If the reference is missing, the sensor is not at fault and the problem is upstream - and other sensors sharing that reference will usually have set codes too.
  3. Check for a good earth at the sensor. A lost earth commonly drives a signal high, which is why P0406 and P0408 are not always a shorted signal wire.
  4. Watch the sensor reading on the live data screen while the valve is commanded through its travel. A reading that never moves confirms a dead sensor or a dead circuit.
  5. On a differential pressure sensor, check its hoses. They perish, split and block with soot, and either fault produces an out-of-range reading from a perfectly good sensor.
  6. Look for other codes sharing the same reference or earth circuit before condemning this sensor.
