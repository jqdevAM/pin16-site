P0965

Pressure Control Solenoid "B" Control Circuit Range/Performance

Severity
High
Driving
Drive only to a garage
System
Powertrain
Group
Transmission and control modules

The control circuit for pressure control solenoid "B" is electrically connected but not behaving as expected - the current drawn does not match what the module commanded. This is the module's view of the same problem P0776 describes from the hydraulic side: the solenoid is not doing what it is told.

Possible causes

  • CommonSolenoid worn or sticking, drawing the wrong current
  • CommonHigh resistance in the wiring or a corroded connector
  • CommonDebris in the fluid restricting solenoid movement
  • PossibleInternal transmission harness deteriorating
  • PossibleLow or degraded fluid
  • RareFailed control module driver

What you might notice

  • Harsh or unpredictable shifting
  • Slipping under load
  • Limp mode
  • Delayed engagement
  • Check engine light on

What to check, in order

  1. Check the fluid level and condition first, and look for debris.
  2. Measure the solenoid resistance at the case connector against specification - a reading slightly out is exactly what produces this code rather than an outright electrical fault.
  3. Perform a voltage drop test on the solenoid circuit to find high resistance in the wiring.
  4. Read all codes. The matching solenoid code identifies the same component from the hydraulic side.
  5. Check whether an adaptation reset is specified after repair.
