U0329

Software Incompatibility with Steering Column Control Module

Severity
Medium
Driving
Drivable — book it in

The software in the steering column control module is not compatible with the rest of the vehicle. Despite the name this module does not steer the car - it reads the stalks and switches on the steering column, so indicators, wipers, lights and horn can all stop responding. On vehicles with an electric steering lock it also controls that, and then the mismatch can prevent the car being started or the steering unlocked.

Possible causes

  • CommonThe steering column control module replaced but never coded to this vehicle
  • CommonUsed module fitted from a different vehicle or specification
  • CommonOption coding not written after fitting - cruise control, rain sensor, headlamp options
  • CommonSoftware update interrupted during programming
  • CommonWrong part number for the trim level

What you might notice

  • Indicators, wipers or headlamp stalks not responding
  • Horn or steering wheel buttons dead
  • Steering lock will not release
  • Vehicle will not start
  • Airbag warning light on as well

What to check, in order

  1. Confirm the indicators and wipers work before driving. Losing indicators is a road safety issue and an inspection failure, even though nothing about the car feels different.
  2. Ask what was done. A column, steering wheel or airbag repair immediately before this appeared is the explanation.
  3. Check the option coding matches the car's actual equipment.
  4. If the steering lock will not release, do not force the wheel - that damages the lock mechanism and turns a software problem into a mechanical one.
  5. If an airbag warning light is on as well, treat the restraints side as the priority and do not work in the column with the battery connected.
