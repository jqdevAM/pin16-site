P2668

Fuel Mode Indicator Lamp Control Circuit

Severity
Low
Driving
No driving restriction
System
Powertrain
Group
Computer output circuits and control module

A fault in the fuel mode indicator lamp circuit. On a bi-fuel vehicle this lamp tells the driver which fuel is being used. The fuel system itself may be working perfectly; what has failed is the indication - which matters mainly because you cannot see which tank you are drawing from.

Possible causes

  • CommonBlown indicator bulb
  • CommonWiring or connector fault to the cluster
  • PossibleFailed instrument cluster lamp driver
  • PossibleCorroded connector behind the cluster
  • RareFailed control module output

What you might notice

  • Fuel mode lamp not lighting or stuck on
  • Cannot tell which fuel is in use
  • Check engine light on
  • Fuel system otherwise working normally

What to check, in order

  1. Check whether the lamp lights during the ignition-on bulb check.
  2. Confirm the vehicle still switches fuels correctly, which tells you this is only an indication fault.
  3. Check the wiring between the module and the cluster.
  4. Note the practical consequence: without the lamp you may run one tank empty without realising, so watch both fuel gauges until it is fixed.
