P0909

Gate Select Control Error

Severity
High
Driving
Drive only to a garage
System
Powertrain
Group
Transmission and control modules

The module commanded the selector shaft to a gate position and it did not get there. The circuit is not being blamed - this is the mechanism physically failing to move as instructed. On a hydraulically actuated gearbox that usually means pressure; on an electrically actuated one it usually means the actuator or the mechanism itself.

Possible causes

  • CommonLow hydraulic pressure - leak, failed pump or accumulator
  • CommonFailing gate select actuator
  • CommonCalibration lost or never performed after a repair
  • PossibleWorn or sticking selector mechanism inside the gearbox
  • PossibleFaulty position sensor misreporting where the shaft is
  • PossibleInternal gearbox damage obstructing the shaft

What you might notice

  • Transmission will not select gears
  • Car stuck in neutral or stuck in one gear
  • Gear changes taking a long time
  • Transmission warning message
  • Car will not move

What to check, in order

  1. Read all codes first. A hydraulic pressure code alongside this one usually explains it, and chasing the actuator would be wasted effort.
  2. Run the calibration procedure. If the code returns immediately afterwards, the fault is mechanical or hydraulic.
  3. Check hydraulic pressure and look for leaks if the system is hydraulically actuated.
  4. Watch commanded against actual gate position on the live data screen.
  5. A gearbox that cannot select a gear may leave you unable to move at all. Do not set out on a journey where being stranded would be a problem.
