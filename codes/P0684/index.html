P0684

Glow Plug Control Module to PCM Communication Circuit Range/Performance

Severity
Low
Driving
Drivable — book it in
System
Powertrain
Group
Computer output circuits and control module

The glow plug control module is communicating, but what it reports is not plausible - the engine module cannot reconcile it with what it expects. Often this means the glow plug module is reporting a fault of its own that the engine module cannot interpret.

Possible causes

  • CommonFailed glow plug or plugs, reported but not resolvable
  • CommonFailed glow plug control module
  • CommonWiring fault corrupting the messages
  • CommonLow battery voltage
  • PossibleSoftware mismatch after a module replacement

What you might notice

  • Hard starting when cold
  • White smoke on a cold start
  • Rough running for the first minute from cold
  • Glow plug light behaving oddly
  • No symptom at all in warm weather
  • Glow plug warning light on

What to check, in order

  1. Read the glow plug module's own codes if the tool can reach it.
  2. Check battery voltage and state of charge.
  3. Test each glow plug individually.
  4. Ask whether a module was recently replaced - an unconfigured module reports things the engine module cannot interpret.
