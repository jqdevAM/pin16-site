P0128

Coolant Thermostat (Coolant Temperature Below Thermostat Regulating Temperature)

Severity
Low
Driving
No driving restriction
System
Powertrain
Group
Fuel and air metering
Important. This code rarely causes drivability problems, but it does cost fuel and it means the engine spends longer than designed running cold, which increases wear.

The engine coolant is not reaching the temperature the module expects within the expected time. It is not overheating - the opposite. The engine is running cooler than designed, which usually means the thermostat is stuck open and letting coolant circulate through the radiator before the engine has warmed up.

Possible causes

  • CommonThermostat stuck open
  • PossibleFaulty coolant temperature sensor reading low
  • PossibleLow coolant level
  • RareCooling fan running constantly when it should not

What you might notice

  • Heater blows cool or takes a long time to warm up
  • Temperature gauge reads lower than normal or takes a long time to rise
  • Worse fuel economy - a cold engine runs a richer mixture
  • Check engine light on

What to check, in order

  1. Watch coolant temperature on the live data screen during a normal drive. If it never reaches roughly the normal operating range, the thermostat is the likely cause.
  2. Check the coolant level when the engine is cold. Low coolant can produce the same symptom.
  3. Feel the heater output. Poor cabin heat alongside this code strongly supports a thermostat stuck open.
  4. The thermostat is usually the cheaper part to replace and the more likely culprit, but confirm the sensor reads plausibly before replacing anything.
