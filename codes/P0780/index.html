P0780

Shift Error

Severity
High
Driving
Drive only to a garage
System
Powertrain
Group
Transmission

The transmission attempted a shift and it did not go as commanded, without the module identifying which shift or which component. It is a general complaint that the shift did not complete properly - too slow, incomplete, or not happening at all.

Possible causes

  • CommonLow or degraded transmission fluid
  • CommonFailed or sticking shift solenoid
  • CommonSticking valve body
  • CommonWorn clutch pack or band
  • PossibleLow line pressure
  • PossibleAdaptation values learned around a developing fault

What you might notice

  • Shifts flaring, slipping or not happening
  • Harsh or delayed shifts
  • Limp mode
  • Check engine light on

What to check, in order

  1. Check the fluid level and condition first.
  2. Read all stored codes. A specific shift code or a solenoid code alongside this one identifies the actual problem.
  3. Note which shifts are affected and whether it is consistent.
  4. Check whether the transmission has ever had a fluid and filter service.
  5. A pressure test is the way to separate hydraulic problems from mechanical wear.
