P0297

Vehicle Overspeed Condition

Severity
Low
Driving
Drivable — book it in
System
Powertrain
Group
Fuel and air metering - injector circuits

The vehicle has been driven faster than a limit set in the module. This is not an engine fault. Speed limiters are fitted for all sorts of reasons - a manufacturer limit, a speed-rated tyre restriction, a fleet or insurance setting, or a limit tied to a particular tyre or wheel specification.

Possible causes

  • CommonVehicle driven above its programmed limit
  • PossibleLimiter set for tyres of a lower speed rating than those fitted
  • PossibleFleet, insurance or telematics limit configured in the module
  • PossibleWrong tyre or wheel size making the module read speed incorrectly
  • PossibleFaulty speed sensor recording a false reading

What you might notice

  • Recorded after a period of high-speed driving
  • Check engine light on
  • Sometimes an audible warning at the limit
  • No effect on how the car drives

What to check, in order

  1. Check the speed rating of the tyres actually fitted. A limiter set for winter or space-saver tyres will trigger long before the car's own maximum.
  2. Check whether a non-standard wheel or tyre size has been fitted, which makes the module calculate speed wrongly.
  3. Check for a fleet, insurance or telematics limiter configured in the vehicle.
  4. If the speed recorded is implausible, suspect a speed sensor fault rather than the driving.
  5. Clear the code and see whether it returns in normal driving.
