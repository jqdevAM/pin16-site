P0600

Serial Communication Link

Severity
High
Driving
Drive only to a garage
System
Powertrain
Group
Computer output circuits and control module

A fault on the serial communication link between control modules. Where a bus code describes the wiring, this describes the module's ability to use it - it cannot exchange data with the modules it depends on, so expect a scatter of other codes that are consequences of this one.

Possible causes

  • CommonDamaged, chafed or corroded bus wiring
  • CommonLow battery voltage, which drops modules off the link
  • CommonCorroded or water-ingressed connector
  • CommonAnother module faulting and disrupting the link
  • PossibleAftermarket electrical work spliced into the bus
  • PossibleFailed control module

What you might notice

  • Several warning lights at once
  • Scan tool cannot reach some modules
  • Limp mode
  • Vehicle will not start
  • A long list of communication codes

What to check, in order

  1. Check battery voltage and state of charge first - a weak battery causes communication faults with no wiring problem at all.
  2. Read every code and look at how many there are. Most will be consequences of this one.
  3. Inspect connectors for water and corrosion.
  4. Ask what was recently fitted, and what is plugged into the diagnostic socket. Aftermarket trackers, alarms and dongles left permanently connected are a frequent cause.
  5. See the U0001-series bus codes for the resistance measurement that identifies a wiring fault on a twin-wire CAN bus.
