P0981

Shift Solenoid "D" Control Circuit Range/Performance

Severity
High
Driving
Drive only to a garage
System
Powertrain
Group
Transmission and control modules

The control circuit for shift solenoid "D" is electrically connected but not behaving as expected - the current drawn does not match what was commanded. This is the module's view of a solenoid that is not doing its job, so it is closely related to the shift solenoid "D" performance code and the two should be diagnosed together when both are stored.

Possible causes

  • CommonSolenoid worn or sticking, drawing the wrong current
  • CommonHigh resistance in the wiring or a corroded connector
  • CommonDebris in the fluid restricting solenoid movement
  • PossibleInternal transmission harness deteriorating
  • PossibleLow or degraded fluid
  • RareFailed control module driver

What you might notice

  • Missing gears or a refusal to shift
  • Harsh or delayed shifts
  • Limp mode
  • Check engine light on

What to check, in order

  1. Check the fluid level and condition first, and look for debris.
  2. Measure the solenoid resistance at the case connector against specification. A reading slightly outside tolerance is what produces this code rather than an outright electrical fault.
  3. Perform a voltage drop test on the circuit to find high resistance in the wiring.
  4. Note which gears are missing - the pattern narrows down which solenoid is genuinely at fault.
  5. Read all codes. A matching shift solenoid code describes the same component from the hydraulic side.
  6. Check whether an adaptation reset is specified after repair.
