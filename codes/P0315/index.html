P0315

Crankshaft Position System Variation Not Learned

Severity
Low
Driving
Drivable — book it in
System
Powertrain
Group
Ignition system or misfire
Important. This is a procedure, not a component. If a repair was just done, running the relearn is the remaining step rather than evidence that the repair went wrong.

The crankshaft position variation relearn procedure has not been completed. This is a calibration, not a fault: every crankshaft and reluctor ring has tiny manufacturing variations, and the module has to measure them before it can tell a genuine misfire from normal irregularity. Until the relearn is done, misfire detection does not work properly.

Possible causes

  • CommonRelearn never performed after a crankshaft sensor replacement
  • CommonRelearn never performed after control module replacement or reprogramming
  • CommonRelearn never performed after engine or timing work
  • CommonRelearn attempted but the required conditions were never met
  • PossibleAnother stored fault preventing the procedure from completing

What you might notice

  • Check engine light on
  • Misfire codes that do not match how the engine feels
  • Misfire detection not working
  • Often no symptom the driver notices

What to check, in order

  1. Ask what was done recently. A crankshaft sensor, engine or module repair immediately before this appeared is the explanation.
  2. Run the relearn procedure. It usually requires a specific set of conditions - a warm engine, and a controlled deceleration in gear - and it must be allowed to finish.
  3. Clear any other stored faults first. The procedure will not complete while another fault is active.
  4. Do not replace parts for this code. Nothing has failed; a calibration is missing.
