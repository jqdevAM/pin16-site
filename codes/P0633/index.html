P0633

Immobilizer Key Not Programmed - ECM/PCM

Severity
Medium
Driving
Short journeys only
System
Powertrain
Group
Computer output circuits and control module

The immobiliser key has not been programmed into the engine control module. The module and the key have to recognise each other before the engine will run, and that link has not been established - typically because the module or a key was replaced and never matched.

Possible causes

  • CommonModule replaced and never configured to this vehicle
  • CommonUsed module fitted from a different vehicle or specification
  • CommonProgramming or coding session interrupted
  • CommonWrong part number for the market, model year or engine variant
  • CommonConfiguration data not transferred during a module swap
  • PossibleAftermarket tuning device altering what the module reports
  • CommonNew or replacement key never programmed
  • CommonEngine module replaced without matching it to the immobiliser

What you might notice

  • Engine turns over but will not start
  • Immobiliser or key warning light
  • One key works and another does not
  • Fault present since a repair or a new key

What to check, in order

  1. Try the spare key. If one works, the fault is the unprogrammed key rather than the vehicle.
  2. Do not switch the engine off far from home until this is resolved.
  3. Expect proof of ownership to be required, and expect a franchised dealer or a properly equipped auto-locksmith rather than a generic tool.
  4. Ask what was done to the vehicle recently. These codes follow work; they do not appear on their own.
  5. Read the software and part numbers of the modules involved and compare them against the vehicle's build specification.
  6. Do not replace the module. The hardware is almost always right and the configuration is missing.
  7. Expect manufacturer-level programming. A generic scan tool can read these codes but cannot resolve them.
  8. If a used module was fitted, check whether it can be transferred to this vehicle at all - some are locked to their original VIN.
