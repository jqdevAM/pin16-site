P0409

Exhaust Gas Recirculation Sensor "A" Circuit

Severity
Medium
Driving
Drivable — book it in
System
Powertrain
Group
Auxiliary emission controls

There is a fault in the circuit for EGR sensor "A" without the module classifying it as high or low - typically an open circuit, an intermittent connection, or a reading that is inside the electrical range but implausible. Sensor "A" is a manufacturer designation rather than a physical position.

Possible causes

  • CommonOpen circuit or broken wire on the sensor "A" circuit
  • CommonLoose, corroded or backed-out connector pin
  • CommonFailed sensor
  • PossibleChafed harness making intermittent contact
  • PossibleLoss of reference voltage or earth

What you might notice

  • Check engine light on, sometimes intermittently
  • EGR system disabled
  • Failed emissions test
  • Often no symptom the driver notices

What to check, in order

  1. Inspect and reseat the connector. An intermittent code with no other evidence is very often a pin that has backed out of its housing.
  2. Wiggle-test the harness with the live data screen showing the sensor reading. A reading that jumps as you move the loom locates the fault to that section.
  3. Measure continuity through the signal wire between the sensor and the module connector.
  4. Check the reference and earth circuits before condemning the sensor.
  5. If the code is intermittent, note the conditions - a fault that appears only when the engine is hot or only over bumps is a wiring fault, not a sensor fault.
