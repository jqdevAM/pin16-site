P0610

Control Module Vehicle Options Error

Severity
High
Driving
Drive only to a garage
System
Powertrain
Group
Computer output circuits and control module

The module's record of what this vehicle is fitted with does not match reality. Modules are configured with an option list - engine variant, transmission type, market, equipment - and when that list is wrong the module makes decisions for a car that does not exist. Nothing has failed; the configuration is wrong.

Possible causes

  • CommonModule replaced and never configured to this vehicle
  • CommonUsed module fitted from a different vehicle or specification
  • CommonProgramming or coding session interrupted
  • CommonWrong part number for the market, model year or engine variant
  • CommonConfiguration data not transferred during a module swap
  • PossibleAftermarket tuning device altering what the module reports

What you might notice

  • Systems behaving as though the car has equipment it does not, or lacks equipment it has
  • Limp mode
  • Several unrelated warning lights
  • Fault present since a repair
  • Check engine light on

What to check, in order

  1. Ask what was done to the vehicle recently. These codes follow work; they do not appear on their own.
  2. Read the software and part numbers of the modules involved and compare them against the vehicle's build specification.
  3. Do not replace the module. The hardware is almost always right and the configuration is missing.
  4. Expect manufacturer-level programming. A generic scan tool can read these codes but cannot resolve them.
  5. If a used module was fitted, check whether it can be transferred to this vehicle at all - some are locked to their original VIN.
