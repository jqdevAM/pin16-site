P0155

O2 Sensor Heater Circuit (Bank 2 Sensor 1)

Severity
Medium
Driving
Drivable — book it in
System
Powertrain
Group
Fuel and air metering

The heater circuit in the upstream oxygen sensor on bank 2 has a fault. Oxygen sensors only work once hot, so each one contains a small heating element to bring it up to temperature quickly after start-up. With the heater dead the sensor takes far longer to start working, or never works at low load, so the engine runs on a default fuel calculation instead.

Possible causes

  • CommonFailed heater element inside the sensor - the sensor must be replaced
  • CommonBlown fuse on the heater circuit
  • PossibleDamaged heater wiring or connector
  • RareRelay or module driver fault on the heater circuit

What you might notice

  • Check engine light on
  • Worse fuel economy, particularly on short journeys
  • Rough running when cold that improves as the engine warms
  • Failed emissions test

What to check, in order

  1. Check the fuse for the oxygen sensor heater circuit. This is the cheapest possible cause and worth eliminating first.
  2. Measure the resistance of the heater element at the sensor connector and compare it against specification. An open circuit means the sensor needs replacing.
  3. Inspect the wiring and connector for heat damage - these run near the exhaust.
  4. If several heater codes appear at once, suspect the shared fuse or relay rather than several failed sensors.
