P0611

Fuel Injector Control Module Performance

Severity
High
Driving
Drive only to a garage
System
Powertrain
Group
Computer output circuits and control module

The fuel injector control module is not performing as expected. This module generates the high voltages that piezo or high-pressure injectors need, and it is reporting that it cannot deliver them reliably. The engine will misfire, lose power, or refuse to run.

Possible causes

  • CommonFailed fuel injector control module
  • CommonFailed or shorted injector loading the module
  • CommonLow or unstable supply voltage
  • CommonCorroded or water-ingressed connector
  • PossibleDamaged wiring between the module and the injectors
  • PossibleWater ingress at the module

What you might notice

  • Severe misfire
  • Engine will not start
  • Loss of power
  • Rough running
  • Check engine light on

What to check, in order

  1. Check battery and charging voltage first - this module needs a stable supply to generate the voltages the injectors need.
  2. Read all codes. Injector circuit codes alongside this one suggest a shorted injector is loading the module rather than the module having failed.
  3. Measure each injector against specification. One shorted injector can take the module down with it.
  4. Inspect the module connector for corrosion and water.
  5. Do not replace the module before eliminating the injectors. Fitting a new module onto a shorted injector damages the new one too.
