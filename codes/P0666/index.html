P0666

PCM/ECM/TCM Internal Temperature Sensor Circuit

Severity
Medium
Driving
Drivable — book it in
System
Powertrain
Group
Computer output circuits and control module

A fault in the module's internal temperature sensor circuit. The module cannot measure its own temperature, so it loses the ability to protect itself by reducing output when it gets hot. Nothing is necessarily overheating - the measurement has simply gone.

Possible causes

  • CommonModule mounted where it gets little airflow, or a blocked cooling path
  • CommonA shorted output making the module work far harder than it should
  • CommonCorroded connector causing high resistance and local heating
  • CommonFailed internal temperature sensor
  • PossibleVery high ambient temperature combined with heavy load
  • PossibleGenuine internal module failure

What you might notice

  • Check engine light on
  • Limp mode in some cases
  • Often no symptom the driver notices

What to check, in order

  1. Read all codes. An over-temperature code alongside this one changes the picture entirely.
  2. Check the module connector for corrosion.
  3. This sensor is inside the module, so if the circuit really has failed the module is the repair - which makes it worth eliminating the supply voltage and connector first.
