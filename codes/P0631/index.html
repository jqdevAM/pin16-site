P0631

VIN Not Programmed or Incompatible - TCM

Severity
Medium
Driving
Drivable — book it in
System
Powertrain
Group
Computer output circuits and control module

The vehicle identification number stored in the transmission control module is missing, or does not match the vehicle. Modules hold the VIN so that they can confirm they belong to this car and so that diagnostic and emissions reporting is traceable. A missing VIN is normal immediately after a module replacement and is fixed by writing it, not by replacing anything.

Possible causes

  • CommonModule replaced and never configured to this vehicle
  • CommonUsed module fitted from a different vehicle or specification
  • CommonProgramming or coding session interrupted
  • CommonWrong part number for the market, model year or engine variant
  • CommonConfiguration data not transferred during a module swap
  • PossibleAftermarket tuning device altering what the module reports

What you might notice

  • Check engine light on
  • Emissions readiness reporting refused
  • Scan tool reporting a blank or wrong VIN
  • Fault present since a module replacement
  • Often no drivability symptom

What to check, in order

  1. Write the VIN to the module. That is the repair.
  2. Expect proof of ownership to be required. VIN programming is deliberately restricted, because it is what stops modules being moved between stolen vehicles.
  3. Note that an emissions test may be refused while the VIN is missing, even if the vehicle is otherwise faultless.
  4. Ask what was done to the vehicle recently. These codes follow work; they do not appear on their own.
  5. Read the software and part numbers of the modules involved and compare them against the vehicle's build specification.
  6. Do not replace the module. The hardware is almost always right and the configuration is missing.
  7. Expect manufacturer-level programming. A generic scan tool can read these codes but cannot resolve them.
  8. If a used module was fitted, check whether it can be transferred to this vehicle at all - some are locked to their original VIN.
