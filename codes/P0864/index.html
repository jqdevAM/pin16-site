P0864

TCM Communication Circuit Range/Performance

Severity
High
Driving
Drive only to a garage
System
Powertrain
Group
Transmission

The transmission module is communicating, but the messages are not what the receiving module expects - corrupted, incomplete, or carrying implausible values. The link works; what travels over it is wrong. This often follows a module replacement that was never coded to the vehicle, or a software mismatch between modules.

Possible causes

  • CommonModule replaced but not coded or configured to the vehicle
  • CommonSoftware version mismatch between modules after a partial update
  • CommonBus wiring damage corrupting messages
  • CommonLow battery voltage causing erratic behaviour
  • PossibleFailed module
  • PossibleAftermarket device injecting traffic onto the bus

What you might notice

  • Transmission stuck in one gear
  • Erratic shifting
  • Warning lights across several systems
  • Gear display wrong
  • Check engine light on

What to check, in order

  1. Ask whether any module has been replaced or updated recently. Coding and software mismatches are the leading cause of this code, and no amount of wiring diagnosis will find them.
  2. Check battery voltage and state of charge.
  3. Check the software versions of the modules involved if the tool can read them.
  4. Inspect the bus wiring and connectors for damage.
  5. Ask whether an aftermarket tracker, dashcam or performance device has been connected to the diagnostic socket or the bus.
