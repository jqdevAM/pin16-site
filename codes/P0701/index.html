P0701

Transmission Control System Range/Performance

Severity
High
Driving
Drive only to a garage
System
Powertrain
Group
Transmission

The transmission control system is working electrically but not behaving as the module expects - shifts happening at the wrong time, taking too long, or not happening at all. This is a performance complaint about the system as a whole rather than a fault named to one component, and on a high-mileage automatic it usually comes down to fluid condition or internal wear rather than an electrical failure.

Possible causes

  • CommonLow or badly degraded transmission fluid
  • CommonInternal wear - clutches, bands or a worn valve body
  • CommonSticking valve in the valve body
  • PossibleFailing shift or pressure control solenoid
  • PossibleFluid of the wrong specification fitted at a previous service
  • PossibleAdaptation values learned around a fault and never reset

What you might notice

  • Harsh, delayed or flaring shifts
  • Transmission stuck in one gear - limp mode
  • Slipping under load
  • Check engine light on

What to check, in order

  1. Check the fluid level and condition first. It is the cheapest check and it explains more transmission complaints than every electrical fault combined.
  2. Read all stored codes from the transmission module. A solenoid or sensor code alongside this one usually names the real fault.
  3. Ask what fluid was used at the last service. Fitting a fluid of the wrong specification causes exactly these symptoms, and it is one of the most common DIY errors on modern automatics.
  4. Check whether the transmission has ever been serviced. Fluid that is dark and smells burnt indicates internal wear that a code cannot see.
  5. Check whether an adaptation reset is specified after repair. A module that has spent months adapting around a fault keeps using those values until it is reset.
