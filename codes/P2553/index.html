P2553

Throttle/Fuel Inhibit Circuit Range/Performance

Severity
High
Driving
Drive only to a garage
System
Powertrain
Group
Vehicle speed control, idle control and auxiliary inputs

The throttle or fuel inhibit circuit is answering, but its state is not plausible - the inhibit appears to be active when nothing has requested it, or the signal does not match what the security system reports.

Possible causes

  • CommonWiring or connector fault on the inhibit circuit
  • CommonFault in the immobiliser or security module driving the circuit
  • CommonCorroded connector
  • CommonAftermarket alarm, immobiliser or remote start spliced into the circuit
  • PossibleChafed harness shorting against the body
  • RareFailed control module input

What you might notice

  • Engine will not start
  • Engine cutting out
  • Reduced power or forced idle
  • Immobiliser or security warning light
  • Check engine light on

What to check, in order

  1. Ask whether an aftermarket alarm, immobiliser or remote start has been fitted. These are wired into exactly this kind of circuit and are a frequent cause of faults that appear weeks later.
  2. Read the immobiliser and security modules for their own codes.
  3. Inspect the connectors and wiring on the circuit.
  4. Watch the inhibit state on the live data screen with the engine running and with a valid key.
  5. Try the spare key. If one key works and the other does not, the fault is the key rather than the circuit.
