P0789

Shift/Timing Solenoid Intermittent

Severity
High
Driving
Drive only to a garage
System
Powertrain
Group
Transmission

The shift/timing solenoid circuit is faulting intermittently. Shift quality varies between journeys and the transmission may drop into limp mode occasionally, recovering after a restart. Intermittent faults here are usually connections rather than the solenoid.

Possible causes

  • CommonLoose or corroded pin at the case connector
  • CommonFluid wicking into the connector
  • CommonInternal transmission harness beginning to fail
  • PossibleSolenoid dropping out when hot
  • PossibleChafed wiring

What you might notice

  • Shift quality varying between journeys
  • Occasional limp mode clearing after a restart
  • Symptoms only once hot
  • Check engine light coming and going

What to check, in order

  1. Note whether it only happens hot, and record the freeze frame fluid temperature if the tool supports it.
  2. Pull the case connector and inspect for fluid and corrosion.
  3. Wiggle-test the external harness with the live data screen showing solenoid status.
  4. Check the fluid level and condition.
  5. Clear the code and see how long it takes to return. That tells you more about an intermittent fault than any single measurement.
