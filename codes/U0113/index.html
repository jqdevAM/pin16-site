U0113

Lost Communication With Emissions Critical Control Information

Severity
Medium
Driving
Drivable — book it in
System
Network and communication
Group
Network communication

The control module has stopped receiving the emissions-related data it expects from another module on the bus. This is a communication fault rather than an emissions fault: nothing is necessarily wrong with the emissions equipment itself, but the module that reports on it has gone quiet, so the vehicle cannot confirm its emissions systems are working. Readiness monitors will not complete while this is stored, which means the vehicle will not pass an emissions test even if it is otherwise perfect.

Possible causes

  • CommonLow battery voltage or a discharged battery, dropping modules off the bus
  • CommonDamaged, chafed or corroded bus wiring
  • CommonCorroded or water-ingressed connector
  • PossibleBlown fuse or corroded earth
  • PossibleFailed module
  • PossibleModule not coded or configured after a previous repair or replacement

What you might notice

  • Check engine light on
  • Readiness monitors not completing
  • Failed emissions test
  • Other lost-communication codes stored alongside
  • Often no drivability symptom

What to check, in order

  1. Check battery voltage and state of charge before anything else. A weak or failing battery drops modules off the bus and sets lost-communication codes with no wiring fault at all - this is the single most common false lead in this whole family.
  2. Check whether this code is current or historic, and whether a battery disconnection or jump start explains it.
  3. Read all stored codes. This one rarely appears alone, and whichever module is missing usually has its own code naming it.
  4. Check fuses, earths and connectors on the bus.
  5. Do not book an emissions test until the readiness monitors have completed after the repair. That takes a mixture of driving conditions and cannot be rushed.
