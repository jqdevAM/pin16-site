U0322

Software Incompatibility with Body Control Module

Severity
High
Driving
Drivable — book it in
System
Network and communication
Group
Network software
Important. Do not clear the other codes and start diagnosing them one by one. A wrongly configured body control module generates codes across the whole vehicle, and every one of them disappears when it is coded correctly.

The software in the body control module is not compatible with the rest of the vehicle. The body control module runs much of the vehicle's electrical behaviour and sits at the centre of its networks, so a configuration mismatch here produces a long list of other fault codes and a great deal of odd behaviour - most of which are consequences rather than separate problems.

Possible causes

  • CommonThe body control module replaced but never programmed or coded to this vehicle
  • CommonUsed module fitted from a different vehicle or specification
  • CommonVehicle option list not written to the module after fitting
  • CommonSoftware update interrupted during programming
  • CommonWrong part number for the market or trim level
  • PossibleOne module updated while others were left at their old versions

What you might notice

  • A large number of fault codes across unrelated systems
  • Central locking, lighting, wipers or windows behaving strangely
  • Options that should be fitted not working
  • Several warning lights at once
  • Fault present since a repair

What to check, in order

  1. Fix this before chasing anything else. Most of the other codes stored are consequences, and diagnosing them individually wastes a great deal of time.
  2. Ask what was done recently, and whether a used or second-hand module was fitted.
  3. Check the vehicle's option coding. A body control module has to be told what the car actually has - sunroof, parking sensors, rear wiper - and an uncoded module behaves exactly like a faulty one.
  4. Read the part number against the vehicle's market and trim level.
  5. Record the full code list before anything is cleared. After the module is coded correctly, far fewer will come back.
  6. This needs manufacturer-level programming and the vehicle's build data.
