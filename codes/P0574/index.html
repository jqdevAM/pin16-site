P0574

Cruise Control System - Vehicle Speed Too High

Severity
Low
Driving
No driving restriction
System
Powertrain
Group
Vehicle speed control, idle control and auxiliary inputs

Cruise control has been cancelled, or refused, because the vehicle is going faster than the system is permitted to control. This is the system working as designed rather than a fault - though it can also appear if the module is reading speed incorrectly.

Possible causes

  • CommonVehicle driven above the cruise control's working range
  • CommonSpeed increasing on a descent beyond what cruise can hold back
  • PossibleWrong tyre or wheel size making the module read speed incorrectly
  • PossibleFaulty vehicle speed sensor
  • RareCruise control module fault

What you might notice

  • Cruise control cancelling at high speed
  • Cruise control refusing to engage
  • Check engine light on
  • No effect on ordinary driving

What to check, in order

  1. Consider whether the speed recorded is plausible. If it is, this is the system doing its job.
  2. Check whether non-standard wheels or tyres have been fitted, which shifts every speed calculation.
  3. Check for vehicle speed sensor codes stored alongside.
  4. Note that cruise control cannot hold speed down a steep hill - it has no way of braking on most vehicles, so it cancels instead.
  5. Clear the code and see whether it returns in normal driving.
