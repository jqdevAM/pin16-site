P0700

Transmission Control System (MIL Request)

Severity
Medium
Driving
Drivable — book it in
System
Powertrain
Group
Transmission
Important. If your scan tool cannot read the transmission module, this code tells you almost nothing. That is a limitation of the tool, not a sign that the fault is minor.

This is not a fault. It is the transmission control module asking the engine module to switch the check engine light on, because the transmission module has stored a fault of its own. The actual problem is recorded as a separate code inside the transmission module, and that is what has to be read. Chasing P0700 itself leads nowhere - it will clear the moment the real fault is fixed.

Possible causes

  • CommonA fault stored in the transmission control module - this code only reports that one exists

What you might notice

  • Check engine light on
  • Any transmission symptom at all, or none
  • Often accompanied by harsh shifts or a limp mode

What to check, in order

  1. Read the transmission control module, not just the engine module. Many basic scan tools only read the engine module, which is why this code so often appears on its own with nothing to explain it.
  2. The real code will be another P07xx to P09xx code stored in the transmission module. Diagnose that one.
  3. Check the transmission fluid level and condition while you are there. Low or burnt fluid causes a large share of the codes that trigger this request.
  4. Do not replace parts based on this code alone. It names no component.
