P2610

ECM/PCM Internal Engine Off Timer Performance

Severity
Low
Driving
No driving restriction
System
Powertrain
Group
Computer output circuits and control module

The module's engine-off timer is not performing correctly. The module times how long the engine has been standing so it knows whether the next start is genuinely cold - many of the self-tests that make up emissions readiness only run after a long enough soak. With the timer unreliable, those tests may never run.

Possible causes

  • CommonLoss of the permanent battery feed to the module
  • CommonBattery disconnected or repeatedly going flat
  • CommonLoose or corroded battery terminals interrupting the permanent supply
  • PossibleInternal module fault
  • PossibleParasitic drain keeping modules awake

What you might notice

  • Emissions readiness monitors not completing
  • Failed or refused emissions test
  • Check engine light on
  • Usually no drivability symptom

What to check, in order

  1. Check the permanent battery feed to the module and the battery terminals. This timer depends on an uninterrupted supply, so a loose terminal resets it every time.
  2. Ask whether the battery has been disconnected or gone flat recently - that explains the code without anything being wrong.
  3. Check for a parasitic drain if the battery goes flat when the car stands.
  4. Do not book an emissions test until the readiness monitors have completed. They need a cold start after a genuine overnight soak, and that cannot be rushed.
