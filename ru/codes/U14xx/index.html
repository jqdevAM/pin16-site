Данные в шине

По шине получены недопустимые, отсутствующие или неправдоподобные данные — сообщение пришло, но его содержимое нельзя использовать.

Для этой системы нет описаний из открытых источников, поэтому коды разобраны по их структуре.

Специфичный для производителя. Обратитесь к источнику для вашей марки и года выпуска.
